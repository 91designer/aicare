# 客戶剩餘資產與預約關懷比對系統 (v2.4 報表美化版)

專為運動物理治療所、健康管理診所、運動表現學院打造的**純前端（HTML/CSS/JS）**客戶剩餘資產與預約關懷比對工具。支援使用者主動上傳公司既定格式之兩張 Excel 表格（`客戶剩餘資產.xlsx` 與 `預約統計.xlsx`），以高效能 **Hash Mapping 索引技術**在瀏覽器本機端極速完成資料比對，防止頁面卡頓。

---

## 🌟 最新架構升級 (v2.3)

### 1. 全模組化拆分架構（維護與調整更快速）
原先集中於 `index.html` 的龐大程式碼已依據責任單一原則（SRP）完整拆分為獨立的 CSS 與 JS 模組。未來若要調整特定功能，僅需修改對應檔案，無須在數千行 HTML 中翻找，修改與載入速度大幅提升：

| 目錄 / 模組檔案 | 功能職責 | 說明與維護情境 |
| :--- | :--- | :--- |
| **`index.html`** | 頁面結構與骨架 | 僅保留純淨 HTML 結構、兩大上傳拖曳框、篩選工具列與依序引入的模組標籤，體積從 107 KB 大幅精簡至 22 KB。 |
| **`css/styles.css`** | 介面樣式表 | 字型引入、現代滾動條美化、拖曳上傳啟用反饋效果等自訂 CSS。 |
| **`js/config.js`** | 全域狀態與設定 | 集中管理 `state`（含資料集、篩選設定、分頁、排序等全域狀態）。 |
| **`js/utils.js`** | 通用工具函式庫 | 日期萃取/轉換 (`extractDateValue`)、HTML 轉義 (`escapeHtml`)、一鍵複製剪貼簿 (`copyToClipboard`)、氣泡通知 (`showToast`)、圖標重繪 (`refreshIcons`)。 |
| **`js/parser.js`** | Excel 檔案讀取器 | 封裝 SheetJS 讀取邏輯 (`readExcelFile`)、拖曳上傳與點擊監聽 (`setupDropzone`)、資產表與預約表檔案解析處理。 |
| **`js/matcher.js`** | 核心比對與歸納引擎 | **Hash Mapping 索引技術**（以會員號為 Key 建立預約索引）、**客戶姓名＋手機號碼歸納演算法**（整合多筆訂單與多卡號）、關懷評級指標與未約天數計算。 |
| **`js/filters.js`** | 多維度篩選與排序 | 門店、治療師、療程品項下拉選單動態生成、**金額門檻篩選（預設排除 0 元資產）**、關鍵字即時搜尋、分類人數統計與頂部看板計算。 |
| **`js/ui.js`** | 表格渲染與互動 | 客戶主列渲染（姓名/手機/卡號複製按鈕、完整生日、剩餘價值 NT$、持有品項）、Accordion 巢狀訂單與預約歷程表、分頁切換控制。 |
| **`js/modal.js`** | 關懷話術產生器彈窗 | 自動帶入客戶名下所有有效療程與剩餘堂數，產生客製化 LINE/簡訊關懷話術並支援一鍵複製。 |
| **`js/export.js`** | 報表匯出與重設 | 雙工作表 Excel 匯出（客戶層級總表 + 重點關懷急迫名單）與系統資料一鍵清空重設 (`resetAllData`)。 |
| **`js/app.js`** | 應用程式生命週期 | `DOMContentLoaded` 初始化、篩選器與事件監聽綁定、初次空狀態渲染。 |

### 2. 使用者主動上傳模式（移除預設資料）
- 介面回歸**純淨待命狀態**，移除預設的一鍵帶入測試樣本按鈕。

## 💎 核心業務功能特色

### 1. 支援「金額篩選」與「一鍵排除 0 元資產」
- **排除 0 元贈送/體驗品項**：預設啟用 `🟢 僅限付費資產 (金額 > $0)`，自動排除贈品與體驗券，聚焦真正購買付費之核心客群。
- **金額級距門檻**：可選全部金額、`≥ $1,000 元`、`≥ $3,000 元`、`≥ $5,000 元`、`≥ $10,000 元 (高價值客)`，或反向篩選 `⚪ 僅 0 元贈品客`。
- **直覺呈現剩餘金額**：主表與 Accordion 明細均顯示「剩餘價值 (NT$)」，頂部儀表板顯示當前篩選總儲值金額。

### 2. 以「會員姓名 ＋ 手機」歸納統整所有訂單
- 同一位客戶若購買多筆訂單、持有不同商品品項（例如專案治療＋運動訓練），系統自動整合為單一客戶列。
- 主表顯示持有療程品項摘要（如 `專案治療 (3)`），總剩餘堂數與總金額自動彙整。
- 點擊展開 Accordion 可分區檢視：
  - **區塊一：名下資產訂單明細**（訂單號、開單時間、品項、剩餘堂數、價值、開單門店、業務人員）。
  - **區塊二：歷史預約明細**（由新到舊展示所有預約日期、時間、項目、狀態、治療師、門店與報到）。

### 3. 一鍵複製姓名、手機與會員號
- **姓名複製**：點擊姓名或旁邊複製圖標，立即複製至剪貼簿。
- **手機號碼**：支援獨立一鍵複製按鈕，並支援點擊快速撥號 (`tel:`)。
- **會員號複製**：會員卡號亦可一鍵複製；若同客戶跨多個卡號亦會清晰標註。

### 4. 姓名後完整生日顯示
- 姓名後方以括號呈現完整年月日生日（格式如：`王小明 (1985-06-12)`），方便核對身份與安排生日關懷。

### 5. 歸屬人員顯示「業績人員」資料，並以「個管師」標題呈現
- **業務導向對齊**：門店資產訂單中的「訂單銷售分配業績人員」實務上即為負責跟進該客戶之**個案管理師（個管師）**。系統優先提取該欄位資料，若無則備援為歸屬人員。
- **欄位標題更新**：主表欄位、訂單明細與 Excel 匯出表頭一律統一以「**個管師**」呈現。
- **智能清潔人名**：自動去除「運動管理師」、「店經理」、「西門運動物理治療所:」等系統前綴冗詞，並在同客戶擁有多筆訂單時去重彙整（如「葉昕瑜」或「葉昕瑜, 林鈺真」）。

### 6. 依照「療程」與「個管師 / 治療師」深度搜尋與篩選 (支援多選 / 複選)
- **個管師 / 治療師支援複選（Multi-Select）**：
  - **下拉複選浮動面板**：點擊選單按鈕可自訂勾選多位個管師/治療師，主動比對任一位被選取人員所屬之客戶（OR 邏輯）。
  - **即時人員搜尋**：面板內置搜尋框，輸入關鍵字可即時過濾人員名單。
  - **一鍵全選與清空**：支援一鍵全選當前可見人員或一鍵清空所有已選條件。
  - **動態徽章顯示**：下拉按鈕即時回饋選擇狀態（如「葉昕瑜 +1位」、「已選 2 位」），未選時則顯示「全部個管師 / 治療師」。
  - **顯示每位人員關聯人數**：選項右側標註該人員名下關聯之客戶人數（如「葉昕瑜 12人」）。
- **療程 / 服務品項下拉選單**：自動彙整商品名稱與預約項目。
- **全方位智慧搜尋框**：支援姓名、手機、個管師、治療師、療程、預約類型、會員號、訂單號混合即時搜尋。

### 7. 預約紀錄清楚呈現「預約類型」(療程 / 再消 / 初診)
- **主表直覺識別**：主表格的「最近預約紀錄」直接標記最近一次預約的類型徽章（天藍色「初診」、琥珀色「再消」、綠色「療程」），讓管理人員一眼看清到診脈絡。
- **Accordion 歷史預約明細獨立欄位**：展開檢視歷史預約時，專設「預約類型」欄位，清楚呈現每筆預約究竟是初診、再消還是療程正課。
- **關鍵字搜尋支援**：智慧搜尋框支援輸入「初診」、「再消」或「療程」，秒級篩選出具備該預約類型的客戶群。
- **Excel 匯出對齊**：工作表 1 與工作表 2 均包含「最近預約類型」與帶有預約類型的歷程摘要。

### 8. Excel 匯出表單精簡與優化（精準欄位、個管師＋治療師並重）
- **欄位精簡去冗**：已刪除冗餘或重複資訊（會員卡號、有效訂單筆數、歸屬人員、距今天數、最近預約時間、關懷建議行動），聚焦店務追蹤關鍵欄位。
- **重點關懷表單命名**：工作表 2 正式命名為「**🚨重點關懷名單(待追蹤)**」，貼合店務追蹤節奏。
- **治療師與個管師並重**：匯出之兩大工作表均完整包含「個管師」與「治療師」獨立欄位，資料絕不遺漏。
- **治療師純淨姓名顯示**：去除「物理治療師」等系統冗詞前綴，僅保留人員姓名（例如：`物理治療師高于鈞` → `高于鈞`、`物理治療師李威甫` → `李威甫`）。

### 9. 專業級 Excel 匯出排版與視覺化（多行自動換行 ＋ 簡潔大分類 ＋ 斑馬底色 ＋ 20% 灰色格線）
- **明細與歷程多行自動換行**：
  - 「有效訂單明細」中不同筆訂單以換行分隔。
  - 「所有預約歷程摘要」中不同預約日期以換行分隔。
  - 儲存格自動啟用 `wrapText` 自動換行，並依多行數量動態延伸列高，避免文字被壓縮截斷。
- **關懷狀態大分類呈現**：
  - 不帶天數後綴（如 `從未預約`、`逾30天未約`、`15~30天未約`、`近期取消未補`、`近期活躍`、`未來有約`），讓 Excel 篩選下拉選單選項乾淨俐落、秒級完成客群篩選。
- **橫列交替底色 (Zebra Striping)**：匯出的工作表資料列自動套用純白（`#FFFFFF`）與淺灰藍（`#F1F5F9`）交替底色，橫向對照閱讀毫不費力、極為清晰。
- **直行 20% 灰色分隔格線**：直行之間以精準 20% 灰色（`#CCCCCC`）格線明確區隔，直行欄位邊界一目了然。
- **深色沈穩標題列**：標題列採用深海軍藍（Slate-800，`#1E293B`）搭配粗體白字與置中排版，具備極佳辨識度。
- **智慧水平對齊與千分位格式**：
  - 剩餘金額與堂數自動向右對齊，並格式化為千分位（如 `15,000`）。
  - 日期、手機、門店、狀態、個管師、治療師、類型自動置中。
  - 姓名、品項清單、訂單明細、預約摘要靠左對齊。

## 🚀 快速使用方式

1. **直接開啟**：
   - 雙擊資料夾中的 `剩餘資產關懷.bat`，或直接以 Chrome / Edge 開啟 `index.html`。
2. **主動上傳檔案**：
   - 將門店系統匯出的《客戶剩餘資產.xlsx》拖曳至左側上傳框 1。
   - 將《預約統計.xlsx》拖曳至右側上傳框 2。
   - 系統會在 1 秒內自動完成 Hash Mapping 建立與歸納，並套用「排除 0 元資產」付費篩選。
3. **篩選與關懷**：
   - 點選上方分類標籤（從未預約、逾30天未約等）或選擇門店/治療師/療程。
   - 點擊「明細」展開檢視訂單與歷史預約，點擊「關懷」產生專屬 LINE/簡訊範本。
4. **一鍵 Excel 匯出**：
   - 點擊右上角「匯出關懷名單 (Excel)」，即可下載內含雙工作表（總表＋重點關懷名單）的完整 Excel 檔案。
